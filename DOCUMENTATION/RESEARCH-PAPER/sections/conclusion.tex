\section{conclusion}
The Automotive Diagnostic and Activity Monitoring (ADAM) System presents comprehensive, scalable, and intelligent diagnostics solutions. It integrates multiple hardware modules, machine learning model,s and a user-friendly mobile interface to offer real-time vehicle diagnostics, driver behavior analysis, and predictive maintenance. By combining OBD-II with additional sensor inputs and processing them using the Raspberry pi 5 it collects and stores data on the cloud and provides insights through a mobile app with multiple functionalities, including an AI chatbot. It not only aids in proactive maintenance, improved fuel efficiency, and personalized user experience but also contributes to safer and greener driving.
